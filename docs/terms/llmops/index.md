# LLMOps 与成本

::: tip 一句话定位
LLMOps 与成本是让 AI 应用「稳定运行、成本可控」的模块：上线后的持续运维、模型调度、降本、监控告警。
:::

## 这个模块包括什么

- **LLMOps**：围绕大模型应用的一整套工程实践。
- **模型路由**：按任务和预算自动选择最合适的模型。
- **成本优化**：系统性地降低 token 消耗和费用。
- **监控告警**：异常时第一时间发现并通知。

## 在 AI 后端开发中的作用

上线不是终点，而是运维的开始。这个模块解决：

1. **持续迭代**（LLMOps）—— Prompt 版本管理、评测回归、观测。
2. **花最少的钱**（模型路由、成本优化）—— 简单任务用小模型、缓存、压缩输入。
3. **出事早知道**（监控告警）—— 延迟飙升、错误率升高、成本超预算时报警。

没有这一层，AI 应用会"越跑越贵、越跑越差、出了问题还不知道"。
